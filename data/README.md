# Data

Download the Indian Premier League archive in JSON format from <https://cricsheet.org/downloads/>
(file `ipl_json.zip`) and save it here as `data/ipl_json.zip`. Do not unzip it; `src/load_data.py` reads the zip directly.

The analysis in the report used the archive with 1,243 matches (2008-04-18 to 2026-05-31). A newer download
may contain more matches, which will change the numbers slightly.
